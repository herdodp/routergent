ROUTERGENT

One app. Many accounts. One unbroken conversation.
A standalone Electron router for snapgent connectors, with automatic failover and shared handoff history.

VIEW ON GITHUB RELEASES

SYS.MODULES

🧭

ROUTER

Selects a webview node (random or pinned), fails over automatically, and writes a .txt handoff so the next node continues the work.

🔌

BRIDGE

Node port of the MCP side of bridge.py. One hub is shared by every node.

🖥️

WEBVIEW NODES

One <webview> per account, each with its own login partition.

🤖

DRIVER

Injected into each webview. Sends prompts, records progress, and reports done or failed.

SYS.FLOW

  1. Click + Node, choose a provider, and log in inside the webview.
  2. Click Start agent on that node. Repeat for other accounts.
  3. Type in the parent prompt. Auto picks a ready node, or pin one.
  4. Replies and tool results appear in one continuous conversation panel.
  5. If a node fails, the router switches to another and sends a handoff summary.

SYS.BOOT

git clone https://github.com/herdodp/routergent.git
cd routergent
npm install
npm start_

SYS.WARNINGS

⚠ Experimental. Known limitations:
  • The driver has not been tested in a real webview; selectors depend on each provider's DOM.
  • Some world: "MAIN" content scripts may be affected because they are injected at dom-ready.
  • Open a new chat on a node before pressing Start agent.
  • Building the portable .exe needs ../snapgent-extension and ../vscode_mcp.exe next to the project.
